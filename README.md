# aventura-espacial
Jogo pedagógico de matemática para o 3º ano do Ensino fundamental. Os estudantes devem resolver desafios de raciocínio lógico-matemático para colocar a sua nave na rota certa.

## Como executar

Abra `index.html` em um navegador moderno (preferencialmente no celular em modo paisagem), ou acesse pelo GitHub Pages: **https://edneiaangelica.github.io/aventura-espacial/**

## Recursos implementados

- Fluxo completo do jogo: tela inicial, narrativas, níveis 1, 2 e 3, desafio final e telas de vitória/derrota.
- Cronômetros de 1 minuto (questões) e 5 minutos (pistas finais).
- Feedback de acerto, erro e tempo esgotado com sons.
- Controle de som, botão de tela cheia e instalação como app (PWA).
